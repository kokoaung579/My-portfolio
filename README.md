# Kaunghtet Sween Portfolio — Exact UI/UX Rebuild

This is a clean standalone Vite + React + TypeScript rebuild of the supplied portfolio, preserving the original visual design and interactions.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## UI/UX preserved

- Fixed glass navigation + active section indicator
- Mobile navigation drawer
- Scroll progress bar
- Cursor aura and animated particles
- Grid/noise background
- Hero typography, code window and orbit visual
- Reveal-on-scroll animations
- 3D hover tilt project cards
- Project detail modal + Escape/overlay close
- Skills progress bars
- Education panel
- Contact form success state
- CV download interaction
- Footer social/navigation links
- Responsive mobile/tablet/desktop layouts
